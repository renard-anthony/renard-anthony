# Anthony Renard

Je conçois des logiciels, du moteur jusqu’à l’interface. Designer de formation, je fonde
**[Quentyx](https://github.com/Quentyx)**, une suite de moteurs en Node.js : chacun fait une seule
chose, s’installe seul, la plupart sans aucune dépendance, et se laisse piloter aussi bien par une
personne que par un agent IA.

### Publié

- **[quentyx-facturx](https://github.com/Quentyx/quentyx-facturx)** : les factures électroniques
  françaises de la réforme, en Factur-X (EN 16931, PDF/A-3). Produire, lire, valider, un serveur MCP
  pour les assistants IA, zéro dépendance, prouvé par les validateurs officiels Mustang et veraPDF.
  Sur [npm](https://www.npmjs.com/package/quentyx-facturx). Le palier Pro envoie les factures par
  une plateforme agréée.
- **[Une facture conforme en quelques lignes](https://gist.github.com/renard-anthony/775c2e47812277b1457e26c8903a1e8b)** :
  produire, puis relire et recalculer.

### English

I design software, from the engine to the interface. A designer by training, I founded
**[Quentyx](https://github.com/Quentyx)**, a suite of Node.js engines: each one does a single thing,
installs on its own, mostly with zero dependencies, and can be driven by a person or by an AI agent.

- **[quentyx-facturx](https://github.com/Quentyx/quentyx-facturx)**: French e-invoices (Factur-X,
  EN 16931, PDF/A-3). Produce, read, validate, an MCP server for AI assistants, zero dependencies,
  proven by the official Mustang and veraPDF validators.
- What I do for clients: websites and web apps, custom engines (e-invoicing, AI agents over MCP,
  integrations), interface design.
